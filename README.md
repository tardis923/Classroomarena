# 四人争霸赛

四人同屏答题比赛游戏。上方 2/3 是动画区（角色吃食物 / 卡丁车竞速 / 合力打魔王），下方 1/3 是四位选手并列的操作区（题目 + 数字键盘）。四位学生可以同时触摸操作，互不干扰。

目前内置**数学口算**题库；后续加入语文等其他学科时，只需替换题目生成器，界面与动画无需改动（见文末说明）。

面向希沃等教室一体机设计，分辨率 1920×1080。

## 怎么玩

双击本地的 `index.html` 也能玩，无需安装任何东西；在线地址与本地版本完全一致。

1. 在设置页选择**游戏模式**、**场景角色**（酒楼包子 / 森林苹果）、**数量**、**难度**（5 档）。
2. 点「开始比赛」，倒计时后开跑。
3. 学生用数字键盘输入答案，按「✔ 确定」提交。

### 三种模式

| 模式        | 动画区表现                                         | 判定           |
| --------- | --------------------------------------------- | ------------ |
| **吃食物大赛** | 四人坐在长桌前，答对就伸手拿食物、张嘴咬两口、咀嚼吞下；答错摇头冒汗            | 先吃完全部食物者获胜   |
| **赛道竞速**  | 四人各乘一辆卡丁车，在四条车道的赛道上；答对立刻冲出一段（扬尘 + 车速线），答错原地打滑 | 先冲过终点线者获胜    |
| **团队闯关**  | 上方悬浮一只「大魔王」，四人把手里的食物当炮弹扔过去砸它；血条见底即过关，共 3 关    | 3 关全通 = 团队胜利 |

- 吃食物模式动画较完整，适合**气氛和表演**；
- 赛道 / 团队模式答完立刻出新题，**练习密度高**，适合**大批量练口算**。

### 反馈强化（三种模式都有）

- **连击**：连续答对会累计连击，2 连起在面板上显示「🔥xN」，3 连、5 连、10 连时角色头顶飘出「三连击！」等大字并爆星星；答错清零，结算页显示「最高连击」。
- **速度奖励**：8 秒内答完飘出「神速！」，结算页记录「最快用时」。
- **答错亮答案**：答错后答案框里会短暂显示正确答案（红字），学生马上知道错在哪，然后自动换新题；不会扣食物、不扣进度，只是浪费时间。
- **全班一起算**：四块面板的题目始终可见，台下同学可以跟着一起心算。

### 结束与轮换

- 点右上角「提前结算」可随时结束并看排行榜；
- 点「再来一局」用同样设置重开，适合上台的 4 人轮换接力。

## 团队闯关 · 自由攻击 RPG（独立文件）

`boss-battle.html` 是一个**完全独立的单文件小游戏**，与上面的主游戏并存、互不影响。双击即可运行，无任何外部依赖（角色、Boss、特效全部用 Canvas 程序化绘制，不需要 `images/` 文件夹）。

- **玩法（自由攻击）**：治疗师 / 雷电法师 / 火系法师 / 冰系法师四人**同时各答各的题**，谁答对谁立刻释放技能，合力打倒三阶段进化的大魔王；Boss 按秒计时出手——普攻随机队友，每隔一段时间放「天降陨石」打击全体。
- **答题区**：四个答题区全程有效、互不干扰，答完立刻来新题，也可以「换一题」。
- **治疗师**：答对一次给**血量最少的队友**回血；累计答对 10 次（可调）触发**全队回血**。
- **两种答题方式自动切换**：数学口算用数字键盘，语文 / 英语题库用 ABCD 四选一大按钮。
- **内置题库**：数学口算（5 档难度，程序生成）＋ 语文知识（24 题）＋ 英语单词（24 题）。语文 / 英语是**示例题库**，直接在 `boss-battle.html` 里搜 `CN_BANK` / `EN_BANK` 往数组里加 `{q, o:[4个选项], a:正确下标}` 即可。
- **教师可调参数**：Boss 血量 / 攻击力 / 出手间隔（秒）/ 大招间隔（秒）/ 大招伤害、四系技能伤害与治疗量、全队治疗触发次数与治疗量、角色血量、灼烧伤害与间隔、冻结秒数、冻结免疫秒数——开局设置页直接填数字。
- **对局统计**：结算页显示总用时、每人答对 / 答错 / 释放技能 / 跳过次数（治疗师另计全队治疗次数）。

> 冻结机制说明：Boss 被冻结后，会获得「冻结免疫」若干秒（默认 12 秒），防止冰系法师把 Boss 无限冻住、整局打不出手。冻结期间 Boss 完全停手，灼烧则按秒持续掉血。

## 放到 GitHub 上用（GitHub Pages）

仓库上传后，开启 Pages 就能当网站访问：

1. 仓库页面 → **Settings** → 左侧 **Pages**
2. **Source** 选 `Deploy from a branch`
3. 分支选 `main`，目录选 `/ (root)` → **Save**
4. 等 1～2 分钟，访问 `https://<用户名>.github.io/<仓库名>/`

> 仓库名如果就叫 `<用户名>.github.io`，则直接访问 `https://<用户名>.github.io/`。

代码里所有资源都是**相对路径**，所以放在子目录里也正常；整个文件夹原样上传即可。

## 文件结构

```

css/style.css       样式（含 1920×1080 等比缩放适配）
js/questions.js     口算题生成器（5 档难度，除法保证整除）
js/scene.js         Canvas 动画：场景、角色状态机、贴图渲染

tools/              换图用的处理脚本（可不带）
```

## 后续想加别的学科怎么办

代码里**只有一处**和"数学"绑定：出题器 `QGen.next(难度)`，返回 `{ text: 题干, ans: 答案 }`。

所以加语文、英语这类**有标准答案的题**，不用动动画和主流程，只要：

1. 新建一个出题器，例如 `js/questions-chinese.js`，同样暴露 `next(难度)` 返回 `{ text, ans }`（比如拼音、看拼音写词、古诗填空）。
2. 在设置页加一行「学科」选项，切换时换掉当前出题器。
3. 让答案支持文字 —— 目前键盘只有数字，加学科时需要换成/增加拼音字母键盘或选择题（ABCD）。

> 简单说：**框架是通用的，要扩展的是"出题器"和"输入键盘"这两块**。
> 如果以后想做成"选择题"形式，改动最小 —— 四块面板换成四个大按钮即可。

## 浏览器兼容

- 推荐：Chrome / Edge（希沃自带浏览器多为 Chromium 内核）
- QQ 浏览器、360 浏览器可以用，但**必须用「极速模式」**，不要用「兼容模式」（IE 内核）。老内核下游戏会自动降级为鼠标/触摸事件并保持可用，设置页会给出提示。
