# 四人争霸赛 + 关卡闯关

四人同屏答题游戏，由两部分组成：**热身赛**（四人争霸赛）负责攒魔力，**关卡挑战**（`boss-battle.html`）是正式闯关——目前开放第一关「魔法师大战魔王」和第二关「植物守卫战」，后续还有海底、太空等关卡。面向希沃等教室一体机设计，分辨率 1920×1080。

## 在线地址

无需下载，浏览器直接打开：

**https://tardis923.github.io/Classroomarena/**

> 网址区分大小写，只有 `Classroomarena`（首字母大写）能打开。建议在希沃浏览器里加到书签或设为主页。

## 游戏循环：热身赛 → 攒魔力 → 关卡挑战

| 文件                | 名字            | 玩法                                    |
| ----------------- | ------------- | ------------------------------------- |
| `index.html`      | **热身赛 · 四人争霸赛** | 四科混合题团队闯关，**通关奖 30 魔力，失败不产魔力**      |
| `boss-battle.html` | **关卡挑战** | 第一关魔法师大战魔王 / 第二关植物守卫战，每次开战消耗 30 魔力门票 |

```
热身赛（数学+语文+英语+安全 混合题，三年级水平，100 秒 60 题）
        ↓ 通关 → 奖励 30 点魔力
结算页出现紫色按钮「挑 战 第 一 关 →」
        ↓ 点击（开战扣掉 30 点门票）
第一关 · 魔法师大战魔王 → 通关 → 永久解锁第二关 · 植物守卫战 → ……
```

**魔力规则（已简化）**：

- 热身赛**通关**（100 秒内答完 60 题）→ 奖励 **30 点**魔力；失败（超时 / 提前结算）→ 不产魔力。
- 关卡挑战**每次开战都要付 30 点门票**，打输门票不退——但班级进度永久保留。
- 存**本机浏览器**（localStorage），关机、关页面都还在；每台一体机各自保存，各班进度天然隔离。
- 老师如果只想让两个游戏各自独立玩，可在关卡挑战的设置页把**「魔力门票」关掉**。

> **⏱ 热身赛限时 100 秒**：右上角显示「剩 xx s」，最后 20 秒变红闪动。
> - 超时 → 黑屏「闯关失败」+ 重来按钮，本局不产魔力。
> - 通关 → 庆祝页显示用时 / 答对题数 / 每人贡献和奖励的 30 魔力，一键挑战第一关。
> 想改时长：打开 `js/game.js`，改最上面的 `var TEAM_TIME = 100;`（单位：秒）。

## 热身赛怎么玩

双击本地的 `index.html` 也能玩，无需安装任何东西；在线地址与本地版本完全一致。

1. 设置页只需选**场景角色**（酒楼包子 / 森林苹果）——模式和难度已固定，零配置开打。
2. 点「开始比赛」，倒计时后开跑：每人 15 题、四人共 60 题。
3. **四科混合题**：数学口算（数字键盘作答）约 40%，语文 / 英语 / 安全知识（ABCD 四选一，即点即判）各约 20%，全部三年级水平。
4. 通关后结算页显示奖励的 30 魔力和班级魔力池进度。

### 答题体验

- **连击**：连续答对显示「🔥xN」，3 连、5 连、10 连飘大字爆星星；答错清零。
- **答错亮答案**：数学题答案框短暂显示正确答案；选择题**亮出正确选项**（绿色高亮），然后自动换新题。
- **全班一起算**：四块面板的题目始终可见，台下同学可以跟着一起答。

## 关卡挑战（`boss-battle.html`）

**关卡制**：每个主题算一关，班级共进度、永久解锁、可反复挑战。

| 关卡 | 主题 | 题库（默认绑定，老师可改） |
| --- | --- | --- |
| 第一关 | 魔法师大战魔王 | 数学口算 |
| 第二关 | 植物守卫战（PvZ 风格） | 安全知识 |
| 第三关 | 海底探险（敬请期待） | 语文知识 |
| 第四关 | 太空漫游（敬请期待） | 英语单词 |

- **关卡选择**在设置页顶部：打过第 N 关就**永久解锁第 N+1 关**；锁定的关卡变灰，点了会提示。
- **班级成长系统**：每通关一次，全班**攻击 / 血量 / 治疗 +2%**（上限 +20%，即通关 10 次满级）——后面的关卡太难打时，多打几轮就整体变强。设置页有成长进度条。
- **门票**：每次开战扣 30 魔力（可调 / 可关），不足时按钮变灰并给出一键回热身赛的按钮。
- **题目难度**（基准年级）和**题库**在**老师设置页**（密码 8888），学生界面不出现。

### 第一关 · 魔法师大战魔王

治疗师 / 雷电法师 / 火系法师 / 冰系法师四人同时各答各的题，谁答对谁立刻释放技能，合力打倒三阶段进化的「知识大魔王」；Boss 按秒出手——普攻随机队友，每隔一段时间放「天降陨石」打击全体。

- **答错就换题**：立即刷新成新题（红闪＋飘字），且我方每累计答错 3 题 Boss 回血 8%（可调）。
- **治疗师**：答对给血量最少的队友回血；累计答对 10 次（可调）触发全队回血；**全员满血时改为给全队套护盾**（可叠加，Boss 大招一击砸碎）。
- **三种答题方式自动切换**：数字键盘（口算）、`>` `<` `=` 大键（比大小）、ABCD 四选一（知识题库）。
- **难度随 Boss 阶段递增**：P1 用基准年级，P2 升一年级、P3 再升一级（封顶六年级）。
- **阶段免疫**：第 2、3 阶段 Boss 免疫灼烧与冰冻；大招间隔 30 → 20 → 10 秒越来越快。
- **💢 愤怒机制**：每倒下一名队友，存活角色攻击力 +10%。
- **跳过 / 换一题上限**：每人每局 6 次，按钮显示剩余次数，用完置灰。

### 第二关 · 植物守卫战（通关第一关后解锁）

机制与第一关完全一致（答题→技能→打 Boss），**换了整套 PvZ 主题**：

- **我方四植物**：向日葵「阳光花」（治疗）、闪电芦苇「雷芦苇」、火炬树桩「小火炬」、寒冰射手「冰豌豆」，草坪花盆底座 + 施法摇摆动画。
- **Boss 换成僵尸博士机甲**：履带 + 驾驶舱里的红眼僵尸博士，三阶段升级（初启动 → 重装 → 狂暴，肩部导弹荚 / 机械钳臂逐渐展开）。
- **大招换巨人僵尸**：从天而降砸出烟尘，一击砸碎坚果墙。
- **坚果墙**：全员满血时治疗改种坚果挡伤害（图标从护盾变成坚果）。
- **💢 机甲怒气（第二关专属）**：**每 20 秒**变怒一次——普通攻击伤害 +8%、出手间隔 -8%，无限叠加，拖得越久越疼，Boss 状态栏常驻显示。
- **小怪波次（纯演出）**：每隔十几秒一群小僵尸从屏幕右侧走进草坪，烘托气氛。
- **背景**：白天蓝天 + 草坪条纹 + 篱笆云朵。

### 题库

题库集中在 **`js/banks.js`**（热身赛与关卡挑战共享）：**语文 262 题** + **英语 145 题** + **安全 209 题**，全部小学范围：

- 语文覆盖古诗文、成语、近反义词、错别字（找正确写法 / 选字填空）、拼音（多音字 / 看拼音写词语）、修辞、关联词、文学常识与传统节日；
- 英语覆盖颜色、动物、食物、文具、家庭、身体、数字、星期月份、天气、交通、日常交际与基础语法；
- 安全知识覆盖交通、消防、防溺水、饮食卫生、用电、居家、校园、防拐防骗、自然灾害、急救、出行共 11 个板块。

- 选项每次抽题随机打乱位置，防止背位置。
- 加题方法：直接在 `js/banks.js` 里往 `CN_BANK` / `EN_BANK` / `SAFE_BANK` 加 `{q, o:[4个选项], a:0}`（正确答案写第一个，加载时会洗牌）。

### 数学出题规则（第一关 + 热身赛，题型按年级累加）

- **三年级**：① 两个两位数相加减（如 `43 + 27`）；② 乘法口诀 ± 一个数（如 `7 × 8 + 36`）；③ 比大小（如 `27 + 18 ○ 53 − 9`）。
- **四年级**：＋ 整除除法；**五年级**：＋ 两位数 × 一位数 ± 一个数；**六年级**：＋ 三位数 ÷ 一位数再加减。
- 所有除法一律整除，减法不出负数；**混合运算结果不超过 200，含乘法的积不超过 150**。

## 放到 GitHub 上用（GitHub Pages）

仓库上传后，开启 Pages 就能当网站访问：

1. 仓库页面 → **Settings** → 左侧 **Pages**
2. **Source** 选 `Deploy from a branch`
3. 分支选 `main`，目录选 `/ (root)` → **Save**
4. 等 1～2 分钟，访问 `https://<用户名>.github.io/<仓库名>/`

> 仓库名如果就叫 `<用户名>.github.io`，则直接访问 `https://<用户名>.github.io/`。

代码里所有资源都是**相对路径**，所以放在子目录里也正常；整个文件夹原样上传即可。

## 文件结构

```
index.html            热身赛「四人争霸赛」页面主体
boss-battle.html      关卡挑战单文件小游戏（第一关魔法师 / 第二关植物守卫战，自包含）
css/style.css         样式（含 1920×1080 等比缩放适配、ABCD 选项按钮）
js/questions.js       口算题生成器 QGen（按年级累加，除法保证整除）
js/banks.js           语文 / 英语 / 安全 三大题库（热身赛与关卡挑战共享）
js/scene.js           Canvas 动画：场景、角色状态机、贴图渲染
js/game.js            热身赛流程、多点触控绑定、音效、设置与结算、魔力结算
images/               热身赛四个角色的贴图 PNG（关卡挑战不用这里的图）
tools/                换图用的处理脚本（可不带）
```

> 两个游戏之间的魔力数据存在浏览器的 localStorage 里，**必须用同一个浏览器、走同一条路径访问**（例如都从 GitHub Pages 打开，或都在本地双击打开），否则两边看到的是各自独立的魔力池。班级进度（关卡解锁 / 通关次数 / 成长）同样存本机，每台一体机各自独立。

## 后续想加新关卡怎么办

1. 在 `boss-battle.html` 的 `STAGES` 数组里把对应关卡的 `locked` 去掉、写好 `subj`（默认绑定学科）。
2. 需要新主题时仿照第二关：加一套 `PVZ_PHASES` / `PVZ_HEROES` 式的主题数据 + 对应绘制分支（背景 / 角色 / Boss / 大招演出），机制代码完全复用。
3. 需要新题库时在 `js/banks.js` 里加一个数组并接入。

## 浏览器兼容

- 推荐：Chrome / Edge（希沃自带浏览器多为 Chromium 内核）
- QQ 浏览器、360 浏览器可以用，但**必须用「极速模式」**，不要用「兼容模式」（IE 内核）。老内核下游戏会自动降级为鼠标/触摸事件并保持可用，设置页会给出提示。
