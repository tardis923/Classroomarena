# 四人争霸赛

四人同屏答题比赛游戏。上方 2/3 是动画区（角色吃食物 / 卡丁车竞速 / 合力打魔王），下方 1/3 是四位选手并列的操作区（题目 + 数字键盘）。四位学生可以同时触摸操作，互不干扰。

目前内置**数学口算**题库；后续加入语文等其他学科时，只需替换题目生成器，界面与动画无需改动（见文末说明）。

面向希沃等教室一体机设计，分辨率 1920×1080。

## 两个游戏：基础版 + 进阶版

| 文件                | 名字            | 玩法                                    |
| ----------------- | ------------- | ------------------------------------- |
| `index.html`      | **四人争霸赛**     | 上面的主游戏。吃食物 / 赛道竞速 / 团队闯关三种模式，**负责产魔力**      |
| `boss-battle.html` | **团队合作知识闯关 · 进阶版** | 主游戏里「团队闯关」的**进阶版**：四名魔法师 + 三阶段大魔王，**消耗魔力** |

两者用**班级魔力**串成一个循环，学生必须先玩基础版、攒够魔力，才能进进阶版：

```
四人争霸赛 · 团队闯关（基础题 0.5 点/题，提高题 1 点/题）
        ↓ 一局内攒够 30 点
结算页出现紫色按钮「挑 战 大 魔 王 →」
        ↓ 点击
跳到「团队合作知识闯关 · 进阶版」，开战扣掉 30 点
        ↓
魔力归零 → 想再打？下一批学生上台重新攒
```

- **只有「团队闯关」模式产魔力**，吃食物大赛和赛道竞速是纯练习，不产魔力。
- **基础题 0.5 点/题，提高题 1 点/题**，按本局四人答对的总题数算，不设上限，不看名次。
- **没攒够 30 点就清零**：一局结束（含「提前结算」）后若魔力池仍不满 30 点，直接归零 —— 这批学生没打进阶版的资格，换下一批学生上台，从 0 点重新开始攒，谁也不占谁便宜。
- 攒够 30 点后魔力会**保留**，等这批学生去打进阶版；开战扣掉 30 点，剩下的留到下次。
- 存**本机浏览器**（localStorage），关机、关页面都还在。
- 老师如果只想让两个游戏各自独立玩，可在进阶版设置页把**「魔力门票」关掉**，开战就不再需要魔力。

> **为什么是 60 题？** 团队闯关**一关定胜负，每人固定 15 题、四人共 60 题**。
> 基础难度 `60 × 0.5 = 30 点`，**正好够换一局进阶版**；提高难度 `60 × 1 = 60 点`，够换两局。
> 打满 60 题的一瞬间魔王倒下、面板停收题，所以答对题数**正好是 60**，不多不少。

## 怎么玩

双击本地的 `index.html` 也能玩，无需安装任何东西；在线地址与本地版本完全一致。

1. 在设置页选择**游戏模式**、**场景角色**（酒楼包子 / 森林苹果）、**数量**、**难度**（基础 / 提高两档）。
2. 点「开始比赛」，倒计时后开跑。
3. 学生用数字键盘输入答案，按「✔ 确定」提交。
4. 一局结束后，结算页会显示**本局赚到的魔力**和**班级魔力池进度**。

### 题目难度：只有「基础」和「提高」两档

| 难度      | 题型                                                                                        |
| ------- | ----------------------------------------------------------------------------------------- |
| **基础** | ① **两位数 ± 两位数，不进位 / 不退位**（如 `41 + 40`、`86 − 25`）；② **两位数 × 一位数，不进位**（如 `23 × 3`）；③ **除数是一位数的简单除法，整除**（如 `48 ÷ 6`） |
| **提高** | ① **两步混合**（如 `36 ÷ 6 + 12`、`18 + 7 × 6`）；② **带括号**（如 `(25 + 15) ÷ 5`、`(30 + 12) × 3`）；③ **同级但需按顺序**（如 `100 − 35 + 28`、`36 ÷ 6 × 2`） |

> 两档都已校验：答案一律为非负整数，除法**一律整除**，绝不出现小数或负数。

### 三种模式

| 模式        | 动画区表现                                         | 判定           | 产魔力 |
| --------- | --------------------------------------------- | ------------ | --- |
| **吃食物大赛** | 四人坐在长桌前，答对就伸手拿食物、张嘴咬两口、咀嚼吞下；答错摇头冒汗            | 先吃完全部食物者获胜   | ❌  |
| **赛道竞速**  | 四人各乘一辆卡丁车，在四条车道的赛道上；答对立刻冲出一段（扬尘 + 车速线），答错原地打滑 | 先冲过终点线者获胜    | ❌  |
| **团队闯关**  | 上方悬浮一只「大魔王」，四人把手里的食物当炮弹扔过去砸它；血条见底即胜利，一关定胜负 | 打空魔王血条 = 团队胜利 | ✅  |

- 吃食物模式动画较完整，适合**气氛和表演**；
- 赛道 / 团队模式答完立刻出新题，**练习密度高**，适合**大批量练口算**；
- **只有「团队闯关」能攒班级魔力** —— 因为进阶版同样是四人合力打魔王，用团队模式攒才顺理成章。其他两个模式纯粹是练习和暖场，不产魔力。

### 反馈强化（三种模式都有）

- **连击**：连续答对会累计连击，2 连起在面板上显示「🔥xN」，3 连、5 连、10 连时角色头顶飘出「三连击！」等大字并爆星星；答错清零，结算页显示「最高连击」。
- **速度奖励**：8 秒内答完飘出「神速！」，结算页记录「最快用时」。
- **答错亮答案**：答错后答案框里会短暂显示正确答案（红字），学生马上知道错在哪，然后自动换新题；不会扣食物、不扣进度，只是浪费时间。
- **全班一起算**：四块面板的题目始终可见，台下同学可以跟着一起心算。

### 结束与轮换

- 点右上角「提前结算」可随时结束并看排行榜；
- 点「再来一局」用同样设置重开，适合上台的 4 人轮换接力。
- 结算页底部有**魔力小条**，下方紫色按钮**「挑 战 大 魔 王 →」**：
  - **团队闯关**且攒够 30 点 → 亮起可点，一键跳进进阶版；
  - **团队闯关**但没攒够 → 提示「攒到 x / 30 点，魔力已清零」，换下一批学生重来；
  - **其他两个模式** → 提示「本模式不产魔力，只有团队闯关能攒」。

## 团队合作知识闯关 · 进阶版（独立文件 `boss-battle.html`）

`boss-battle.html` 是一个**完全独立的单文件小游戏**，与上面的主游戏并存、互不影响。双击即可运行，无任何外部依赖（角色、Boss、特效全部用 Canvas 程序化绘制，不需要 `images/` 文件夹）。页面标题为**「团队合作知识闯关 · 进阶版」**。

它是主游戏「团队闯关」模式的**进阶版**：同样的四个人一起打魔王，但每个人都有自己的职业和技能。

### 进门前先攒魔力

- 首页顶部会显示**班级魔力进度条**（当前点数 / 30 点）。
- 魔力**不足 30 点**时，「开始战斗」按钮变灰显示**「魔 力 不 足」**，点了也开不了战，下方会多出一个按钮**「先去「四人争霸赛」玩团队闯关攒魔力 →」**，一键跳回主游戏。
- 开战**扣掉 30 点**班级魔力，打完想再战，得回基础版继续攒。
- 老师可在设置页（密码 8888）里改**开战消耗点数**，或把**「魔力门票」整项关掉**（关掉后不需要魔力，随时能开战）。设置页底部的**「魔力清零」**可把班级魔力池归零。

- **玩法（自由攻击）**：治疗师 / 雷电法师 / 火系法师 / 冰系法师四人**同时各答各的题**，谁答对谁立刻释放技能，合力打倒三阶段进化的大魔王；Boss 按秒计时出手——普攻随机队友，每隔一段时间放「天降陨石」打击全体。
- **答题区**：四个答题区全程有效、互不干扰，答完立刻来新题，也可以主动「换一题」。
- **答错就换题**：答错不再原地重做，该答题区**立即刷新成一道新题**（红闪＋飘字提示）。
- **答错会养 Boss**：我方**每累计答错 3 题**，Boss 就回复**总血量的 8%**（次数与百分比可在设置页调）。答题区状态栏会显示每人累计答错数。
- **治疗师**：答对一次给**血量最少的队友**回血；累计答对 10 次（可调）触发**全队回血**。
- **三种答题方式自动切换**：数学口算的「等于」题用数字键盘；数学的「比大小」题用 `>` `<` `=` 三个大键；语文 / 英语题库用 ABCD 四选一大按钮。
- **难度档位**：**三年级 / 四年级 / 五年级 / 六年级**四档（已去掉一、二年级）。
- **数学出题规则**（题型按年级**累加**）：
  - **三年级**：① **两个两位数相加减**（如 `43 + 27`、`90 − 56`）；② 乘法口诀 ± 一个数（如 `7 × 8 + 36`）；③ **比大小**（如 `27 + 18 ○ 53 − 9`）。
  - **四年级**：三年级题型 ＋ **整除除法**（如 `72 ÷ 8`）。
  - **五年级**：四年级题型 ＋ **两位数 × 一位数 ± 一个数**（如 `36 × 7 − 25`）。
  - **六年级**：五年级题型 ＋ **三位数 ÷ 一位数，再加减一个数**（如 `840 ÷ 4 + 26`）。
  - 所有除法**一律整除，绝不出现小数点**；减法结果不会出现负数。
  - **比大小题**：左右各是两个数字的运算（＋ − × ÷ 都可能，左右运算符通常不同），**两边结果差距不超过 5**，不会一眼看出也不会过于悬殊。
- **难度随 Boss 阶段递增**：设置页选的是**基准年级**，P1 用所选年级，**P2 升一年级，P3 再升一年级**（封顶六年级；已封顶则加大数值）。Boss 变身一次，题目跟着变难。
- **内置题库**：数学口算（4 档，程序生成）＋ **语文知识（72 题）** ＋ **英语单词（72 题）**，全部在小学知识范围内：语文覆盖古诗文、成语、近反义词、字词错别字、修辞、文学常识、关联词句式；英语覆盖颜色、动物、食物、文具、家庭、身体、数字、星期月份、天气季节、交通地点、日常交际与基础语法。直接在 `boss-battle.html` 里搜 `CN_BANK` / `EN_BANK` 往数组里加 `{q, o:[4个选项], a:正确下标}` 即可。

### 难度已固定为中等，参数藏在密码后

默认参数按**小学生平均水平**调成**中等难度**（一局约 3～4 分钟，答得快准就能赢，磨蹭或乱答就会被 Boss 拖死）：

- **首页只显示「题库」和「题目难度」两项**，学生拿不到就能直接开打；
- 所有战斗数值（Boss 血量 / 攻击 / 出手与陨石间隔 / 各系伤害 / 治疗量 / 护盾 / 灼烧冻结 / 答错回血）都移到了**左上角「设 置」按钮**里，需要输入**管理密码（初始 8888）**，密码键盘专为触摸屏设计；
- 设置页改完点**「保存配置」**，参数写入**本机浏览器**（localStorage），下次打开自动生效；「恢复默认」一键回到中等难度；也可以顺手改管理密码；
- 战斗中也能打开设置，会**自动暂停**，关闭后继续。
- 另外已**屏蔽鼠标右键**，并新增**右上角「全 屏」按钮**（一键进 / 退全屏）。

- **对局统计**：结算页显示总用时、每人答对 / 答错 / 释放技能 / 跳过次数（治疗师另计全队治疗次数与套盾次数）。

> **护盾机制**：当全队都是满血时，治疗师答对不再浪费治疗量，而是**给全队每人套上护盾**（默认 +60，可叠加至上限 240）。护盾会**优先替角色挡下 Boss 的伤害**，挡完才扣血。
>
> **冻结机制**：Boss 被冻结后，会获得「冻结免疫」若干秒（默认 12 秒），防止冰系法师把 Boss 无限冻住、整局打不出手。冻结期间 Boss 完全停手，灼烧则按秒持续掉血。

## 放到 GitHub 上用（GitHub Pages）

仓库上传后，开启 Pages 就能当网站访问：

1. 仓库页面 → **Settings** → 左侧 **Pages**
2. **Source** 选 `Deploy from a branch`
3. 分支选 `main`，目录选 `/ (root)` → **Save**
4. 等 1～2 分钟，访问 `https://<用户名>.github.io/<仓库名>/`

> 仓库名如果就叫 `<用户名>.github.io`，则直接访问 `https://<用户名>.github.io/`。

代码里所有资源都是**相对路径**，所以放在子目录里也正常；整个文件夹原样上传即可。

```

js/game.js            游戏流程、多点触控绑定、音效、设置与结算、魔力结算
```

## 后续想加别的学科怎么办

代码里**只有一处**和"数学"绑定：出题器 `QGen.next(难度)`，返回 `{ text: 题干, ans: 答案 }`。

所以加语文、英语这类**有标准答案的题**，不用动动画和主流程，只要：

1. 新建一个出题器，例如 `js/questions-chinese.js`，同样暴露 `next(难度)` 返回 `{ text, ans }`（比如拼音、看拼音写词、古诗填空）。
2. 在设置页加一行「学科」选项，切换时换掉当前出题器。
3. 让答案支持文字 —— 目前键盘只有数字，加学科时需要换成/增加拼音字母键盘或选择题（ABCD）。

> 简单说：**框架是通用的，要扩展的是"出题器"和"输入键盘"这两块**。
> 如果以后想做成"选择题"形式，改动最小 —— 四块面板换成四个大按钮即可。

## 浏览器兼容

- 推荐：Chrome / Edge（希沃自带浏览器多为 Chromium 内核）
- QQ 浏览器、360 浏览器可以用，但**必须用「极速模式」**，不要用「兼容模式」（IE 内核）。老内核下游戏会自动降级为鼠标/触摸事件并保持可用，设置页会给出提示。
