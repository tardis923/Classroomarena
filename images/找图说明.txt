角色图片取材要求（熊大 / 熊二 / 光头强 / 蹦蹦）
================================================

一、图片要长什么样
  1. 一张图里【只有一个】角色（不要合影、不要大合照）
  2. 取【半身】（头 + 上半身，腰以上），不要全身照、不要大头贴
  3. 【正面或微微侧】，不要背面、不要低头
  4. 嘴巴要露出来、不要被手/道具/围巾挡住（吃苹果时要张嘴）
  5. 背景越简单越好：纯白 / 纯色 / 已经抠好的透明底 PNG 最佳
     （森林、草地、房间这类实景背景，自动抠图抠不干净）
  6. 尺寸：高度 ≥ 500px，长宽比接近 3:4 ~ 1:1
  7. 四个角色最好都是同一种画风（要么都是动画截图，要么都是手绘）

二、文件命名（必须带中文名，脚本靠它辨认角色）
  熊大.png      熊二.png      光头强.png      蹦蹦.png
  例：熊大.jpg / 熊二.png / 光头强.jpg / 蹦蹦.png

三、两步走
  1. 把 4 张图放进  baozi-game/tools/input/
  2. 在项目根目录执行：
     python tools/make_avatars.py tools/input/熊大.jpg tools/input/熊二.jpg tools/input/光头强.jpg tools/input/蹦蹦.jpg
     （直接写  python tools/make_avatars.py  也会自动扫描 input/ 目录）
  3. 生成的四个透明 PNG 会自动写入 images/，打开游戏、选「森林」主题即可生效。

四、其他
  · 四个角色可以逐个替换，没图的那个会先用内置的简笔角色，互不影响。
  · 图片仅用于本机课堂教学，请自行注意素材来源。
